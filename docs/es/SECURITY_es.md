# Política de Seguridad

## Versiones Soportadas

Solo la última versión estable de Alenia Fuse cuenta con soporte activo y actualizaciones de seguridad.

| Versión | Soportada |
| ------- | --------- |
| v2.0    | Sí        |
| < v6.5  | No        |

## Reportar una Vulnerabilidad

Nos tomamos muy en serio la seguridad de Alenia Fuse. Si encuentras alguna vulnerabilidad o problema de seguridad, por favor no abras un issue público en GitHub. En su lugar, repórtalo de forma privada a nuestro correo oficial:

**contact.aleniastudios@gmail.com**

Por favor, incluye los siguientes detalles en tu reporte:
- Una descripción de la vulnerabilidad y su impacto potencial.
- Pasos para reproducir el problema (incluyendo scripts de prueba de concepto o comandos).
- La versión de Alenia Fuse y el sistema operativo donde se encontró el problema.

Acusaremos recibo de tu reporte dentro de las primeras 48 horas y trabajaremos contigo para coordinar un parche de seguridad antes de la divulgación pública.
