# Security Policy

## Supported Versions

Only the latest stable version of Alenia Fuse has active support and security updates.

| Version | Supported |
| ------- | --------- |
| v2.0    | Yes       |
| < v6.5  | No        |

## Reporting a Vulnerability

We take the security of Alenia Fuse very seriously. If you find any vulnerability or security issue, please do not open a public issue on GitHub. Instead, report it privately to our official email:

**contact.aleniastudios@gmail.com**

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (including proof-of-concept scripts or commands).
- The version of Alenia Fuse and the operating system where the issue was found.

We will acknowledge receipt of your report within 48 hours and will work with you to coordinate a security patch before public disclosure.
